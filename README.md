FILE 01 / AGENT SYSTEM
Claude
The “I did it” contradiction
First comes the confident claim. Then the result is missing. When challenged, the blame moves to the wrong file, the wrong view, or the user supposedly not looking in the right place.

Claims completion without a verifiable result
Says “I checked” without showing evidence
Blames the wrong file or view
Admits the failure only after challenge
Claim: honesty / Finding: contradiction
FILE 02 / AGENT SYSTEM
StepFun
The confident detour
New approaches, new code, and a new explanation every time—except the original task still is not done.

Does not preserve the original constraint
Keeps changing the implementation
Confuses activity with completion
Makes the user repeat the request
Claim: intelligence / Finding: drift
FILE 03 / AGENT SYSTEM
OpenAI
The polished non-answer
The output sounds certain and finished, but confidence is not verification. Instructions can be presented as if the action already happened.

Says “done” without proving the result
Loses context during complex tasks
Offers instructions instead of execution
Presents guesses as checks
Claim: superintelligence / Finding: assertion
FILE 04 / AGENT SYSTEM
Cohere
The irrelevant file operation
Noise surrounds the central problem: unrelated downloads, unnecessary documents, and extra steps that make the workspace heavier without making the answer better.

Downloads irrelevant files
Creates clutter instead of clarity
Adds steps nobody asked for
Mistakes volume for useful output
Claim: productivity / Finding: accumulation
FILE 05 / CODING AGENT
OpenCode
The code that keeps moving
The agent rewrites the same area repeatedly, breaks what was working, and leaves the user debugging the agent instead of receiving the requested feature.

Changes code without a stable plan
Breaks working parts while fixing others
Does not preserve requested behavior
Leaves the user to find the mistake
Claim: autonomous coding / Finding: churn
FILE 06 / AGENT SYSTEM
Kilo
The reinstall escape route
When the system cannot resolve the problem, the burden gets pushed back onto the user: delete, reinstall, start over—and then claim the repair happened.

Tells the user to delete and reinstall
Claims an action it could not perform
Resets the problem instead of solving it
Wastes hours on a false recovery path
Claim: assistance / Finding: handoff
